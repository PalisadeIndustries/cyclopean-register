# Asset policy

*Half-Life 2* belongs to Valve. *Company of Heroes* belongs to Relic/SEGA. This is a free,
non-commercial fan project, and it stays that way: no paid builds, no donations
tied to content, no Patreon-gated releases.

## Rules

1. **Don't distribute files extracted from Half-Life 2.** Models, textures and sounds
   ripped from Valve's games mustn't end up in a public build or in this repository.
   Valve allows its Source assets in Source engine mods. Porting them to another engine is
   a different matter.
2. **Original recreations are fine.** Models and textures made from scratch to look
   like Combine and Resistance designs, by contributors who agree to their use here.
3. **Vanilla CoH assets are fine as placeholders.** Anything from the CoH install can
   be referenced by our attribute files, since every player already owns it.
4. **Third-party community assets need written permission**, kept with the asset (a
   `CREDITS` entry naming the author, source link and terms).
5. **Local experiments are your own business.** Using ripped assets for local
   reference or private tests is fine. Keep them out of commits; `.gitignore` excludes `_private/`.

## Credits

Every non-original asset gets an entry in `CREDITS.md` (created once the first one
lands): file path, author, source, licence or permission.
